# quant-from-scratch

Mein Lernprojekt: die Serie "Quant Finance from Scratch" selbst nachbauen, bis zu einer eigenen Strategie im Paper Trading.

- `curriculum.md`: alle Teile mit Link, Phase und Voraussetzungen
- `notebooks/`: ein Notebook pro Teil mit der Lernschleife (Abruf, Verstehen, Selbst bauen, Vergleichen, Variieren, Feynman, Transfer)
- `fortschritt.md`: Status nach jeder Sitzung, auch ins Claude-Projekt legen
- `ai_log.md`: jede KI-Nutzung
- `notes.md`: Feynman-Notizen

Regel: Ein angefangener Baustein wird fertig gemacht, dann wird pausiert.
